# India Wander — adventure travel game

3D diorama travel game across India’s states. Built with Vite + React Three Fiber.

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3002

## Deploy (Vercel)

- Framework: Vite
- Build: `npm run build`
- Output: `dist`
- Security headers are set in `vercel.json`
